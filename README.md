# Сервис прогнозирования популярности локаций для размещения банкоматов

## Описание проекта
Проект разработан на основе открытого соревнования **Happy Data Year**, где ставилась задача предсказать **индекс популярности геолокации** для размещения устройств банкоматной сети.

Мы расширяем задачу до уровня **прикладного ML-сервиса**: пользователь отправляет **адрес** или **координаты** - и получает прогноз популярности выбранной локации с учетом инфраструктуры, плотности населения, конкуренции и транспортной доступности.

Сервис реализован как **FastAPI API**, включает:
- инференс модели **LightGBM (Optuna)** — `models/lightgbm_best.txt` или MLflow Registry
  (`GeoATM-LightGBM-PRD`), источник задаётся переменной `MODEL_URI`;
- препроцессинг признаков (log1p расстояний, импьютинг медианами, категориальные) как при обучении;
- real-time сбор 67 признаков по координатам через **OpenStreetMap Overpass API**
  (POI-группы, центр города, land-use) + джойн экономической/региональной статистики из `data/new_stats/`;
- геокодинг / обратный геокодинг через **Yandex Geocoder**;
- логирование каждого запроса в БД + просмотр истории.

## Структура API (эндпоинты)

### `POST /forward`
Принимает **один из двух форматов**:
- `{"address": "...", ...}`  
или
- `{"lat": 55.75, "lon": 37.61, ...}`

Возвращает:
```json
{
  "atm_id": "string",
  "popularity_index": 0.12,
  "segment": "high",
  "coords": {"lat": 55.7558, "lon": 37.6173}
}
```

### `GET /history`
Возвращает историю запросов к сервису.

**Параметры запроса:**
- `limit` — количество записей  
  - по умолчанию: `50`  
  - максимум: `500`
- `offset` — смещение (для пагинации)  
  - по умолчанию: `0`

---

### `DELETE /history`
Полностью очищает историю запросов.

**Требуемый заголовок:**
- `X-Confirm-Token: <HISTORY_DELETE_TOKEN>`

> ⚠️ Токен должен совпадать со значением переменной окружения  
> `HISTORY_DELETE_TOKEN`, заданной на сервере.

---

### `GET /stats`
Возвращает агрегированную статистику по всем залогированным запросам.

**Содержит метрики:**
- `total_requests` — общее количество запросов
- `latency_ms`:
  - `mean`
  - `p50`
  - `p95`
  - `p99`
- `json_num_fields` — количество полей в JSON-запросе
- `json_size_bytes` — размер JSON-запроса в байтах
- `address_len` — длина строки адреса
- `address_tokens` — количество токенов в адресе

## Ключевая метрика

Оценка точности модели производится по **RMSE (Root Mean Squared Error)**:

$$
RMSE = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(y_i - \hat{y_i})^2}
$$

## Быстрый старт (запуск API)

### 1) Установка зависимостей
```bash
pip install -r requirements.txt
```
### 2) Настройка окружения
Создайте файл `.env` (можно скопировать из `.env.template`) и заполните как минимум следующие переменные:

- YANDEX_GEOCODER_API_KEY  
- DATABASE_URL 
- HISTORY_DELETE_TOKEN  
- MODEL_URI — источник модели (по умолчанию `models/lightgbm_best.txt`; для MLflow: `models:/GeoATM-LightGBM-PRD/1`)  

### 3) Запуск сервиса
Из корня проекта выполните команду:
```bash
uvicorn main:app --reload
```
### 4) Swagger / OpenAPI
После запуска сервиса будут доступны:

- Swagger UI:  
  http://127.0.0.1:8000/docs

- OpenAPI JSON:  
  http://127.0.0.1:8000/openapi.json
